# Changelog

## 1.0.0
* Hotkeys `U` / `P` to raise and lower the elevation of the held part, `\` to return it to automatic elevation.
* On-screen readout of the held part's floor and its attached parts.
* `elevation.ini` settings: `max_floor`, `sync_children`, `child_offset`, `overlay`.
* Refuses to run on any build other than Steam 1.163.
